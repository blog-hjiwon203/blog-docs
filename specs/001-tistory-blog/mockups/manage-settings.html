이 화면이 부르는 API

화면의 파란 번호가 아래 줄이다. 글자 번호(A, B, C)는 같은 틀의 화면이 모두 부르는 공통 API다. 경로와 응답은 REST API 명세를 따른다.

#언제요청메모
A화면 열 때GET /api/me401이면 로그인 화면으로(돌아올 주소 포함)
B화면 열 때GET /api/blogviewer.isOwner가 false면 403 화면. 이용 제한이면 restriction 사유 띠
1이미지 고를 때POST /api/images
2저장PATCH /api/blog{ name, description, profileImageId }
3꾸미기 적용PATCH /api/blog{ skin, listLayout, accentColor }. 포인트 색은 6색 중 하나(기본 BLUE)
4화면 열 때GET /api/me/blogs이사 대상 후보(이 블로그 제외)
5이사 지정PUT /api/blog/moved-to{ targetBlogId }
6지정 취소DELETE /api/blog/moved-to
7화면 열 때GET /api/blog/deletion-preview{ remainingPostCount, isPrimary }
8삭제DELETE /api/blog{ confirmAddress }. 204 후 마이페이지로
9화면 열 때GET /api/blog/sidebar/modules모듈 8개의 순서·표시 여부(숨긴 것 포함)
10사이드바 저장PUT /api/blog/sidebar/modules[{ moduleType, isVisible }] 8개 전체를 새 순서로. PROFILE을 숨기면 400
