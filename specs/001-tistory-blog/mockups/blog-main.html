이 화면이 부르는 API

화면의 파란 번호가 아래 줄이다. 글자 번호(A, B, C)는 같은 틀의 화면이 모두 부르는 공통 API다. 경로와 응답은 REST API 명세를 따른다.

#언제요청메모
A화면 열 때GET /api/me로그인 상태. 401이면 비회원
B화면 열 때GET /api/blog블로그 이름·주인·구독 여부. 404면 404 화면
C화면 열 때GET /api/blog/sidebar사이드바 전체(카테고리 트리, 태그, 최근 글·댓글 5)
1화면 열 때·페이지GET /api/posts?page=&size=&categoryId=&tag=10개씩. 카테고리·태그 주소면 조건을 붙임
2구독하기PUT /api/blogs/{blogId}/subscription{ subscribed, subscriberCount }로 숫자 갱신. 비회원이면 401 → 로그인
3구독 취소DELETE /api/blogs/{blogId}/subscription
  • 이사한 블로그 주소로 들어오면 서버가 화면 주소 단계에서 새 블로그로 301한다. 프론트가 할 일은 없다.
