이 화면이 부르는 API

화면의 파란 번호가 아래 줄이다. 글자 번호(A, B, C)는 같은 틀의 화면이 모두 부르는 공통 API다. 경로와 응답은 REST API 명세를 따른다.

#언제요청메모
A화면 열 때GET /api/me로그인 상태·닉네임·대표 블로그. 401이면 비회원 머리글
B화면 열 때(회원)GET /api/me/notifications/unread-count종 아이콘의 읽지 않은 알림 수
1검색·탭·페이지GET /api/search?q=&type=post&page=글 10개씩, 페이지 번호
2블로그 탭GET /api/search?q=&type=blog&page=블로그 이름·소개 검색
