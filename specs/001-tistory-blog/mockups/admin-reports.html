이 화면이 부르는 API

화면의 파란 번호가 아래 줄이다. 글자 번호(A, B, C)는 같은 틀의 화면이 모두 부르는 공통 API다. 경로와 응답은 REST API 명세를 따른다.

#언제요청메모
A화면 열 때GET /api/merole이 ADMIN이 아니면 403 화면
1화면 열 때GET /api/admin/reports?status=PENDING&page=대상별 묶음
2행 누를 때GET /api/admin/reports/{targetType}/{targetId}신고 목록
3처리POST /api/admin/reports/{targetType}/{targetId}/resolve{ result, reason, reasonDetail, period }
  • 신고 없이 바로 숨기거나 해제할 때는 POST·DELETE /api/admin/posts/{id}/blind, /api/admin/comments/{id}/blind, /api/admin/blogs/{id}/restriction을 쓴다(글·댓글 상세의 관리자 메뉴).
