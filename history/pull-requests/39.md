## 문제
운영 `/@hjiwon/5`(카테고리 개발 > 백엔드에 든 글)을 블로그 주인이 아닌 사람(비회원 포함)이 열면 500 INTERNAL_ERROR가 났습니다.

```
LazyInitializationException: Could not initialize proxy [Category#4] - no session
  at Category.isHidden
  at PostVisibilityPolicy.decideInOwnBlog
  at SpaForwardController.blogPage
```

## 원인
글 주소 화면(`SpaForwardController`)은 트랜잭션 밖에서 `PostVisibilityPolicy`로 볼 수 있는지 판단합니다. `PostRepository.findWithBlogById`가 카테고리는 함께 읽지만 **상위 카테고리는 지연 로딩 프록시**로 남겨, 비공개 카테고리 확인(`Category.isHidden()`)에서 터졌습니다. 주인은 카테고리를 보기 전에 통과하므로 나지 않습니다. PostgreSQL 이전과는 상관없이 원래 있던 버그입니다.

## 고친 것
- `findWithBlogById`에 `left join fetch c.parent` 추가(상위 카테고리도 함께 읽음)
- `SpaForwardIntegrationTest.postInSubcategoryIsCheckedWithParentCategory`: 하위 카테고리 글을 비회원·다른 계정·주인이 열면 200, 상위 카테고리를 비공개로 바꾸면 404. 고치기 전 코드에서 500으로 실패하는 것을 확인
