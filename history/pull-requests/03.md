## 작업
- **T007, T008** JWT 쿠키 인증(Nimbus HS256, `Domain=.{platform}; HttpOnly; SameSite=Lax`), `/api/admin/**`는 ADMIN만, `X-Requested-With` CSRF 대책, 401·403도 COM-02 모양. 요청마다 회원 상태 확인: 정지 회원은 API 요청부터 403 `MEMBER_SUSPENDED`(사유, 사유 문구, 정지 종료 시각)와 쿠키 삭제
- **로그인 유지(AUTH-03)**: 고르면 Refresh 14일, 고르지 않으면 무활동 30분 뒤 로그아웃(요청마다 연장, `app.auth.idle-timeout`). Access 토큰이 끝나면 필터가 Refresh 토큰으로 새로 준다
- **T009, T050** Host → 블로그(`BlogHostResolver`), `@CurrentBlog`, 블로그 가시성(`BlogVisibilityPolicy`), 주인 검사(`BlogOwnerGuard`, 404 → 401 → 403 순서)
- **T011** 글 가시성 `PostVisibilityPolicy`(결과 6개: 404, 301, 주인, 주인+숨김, 보임, 구독 안내)와 목록용 `PostSpecifications`
- **T010** `SpaForwardController`: 화면 주소는 블로그·글 확인 뒤 `index.html`, 없으면 404 화면, 이사·다른 블로그 글은 301
- **T016** `@Idempotent` + `Idempotency-Key`: 첫 응답을 Redis에 10분 저장해 같은 키에 그대로 돌려줌. 키 없으면 400
- **T015** 프론트: 플랫폼/블로그 주소 라우터(react-router 7), API 클라이언트(CSRF 헤더, 연타 방지 키, 401 → 플랫폼 로그인 후 원래 주소로), Vite 개발 서버를 `.blog.test` 주소로도 엶

## 명세와 다른 점 (지원 확인함)
- 탈퇴 회원: 401 대신 쿠키를 지우고 비회원으로 처리(로그인이 필요한 요청은 그대로 401)
- 정지 회원 403은 `/api/` 요청에만. 화면 요청은 비회원으로 그리고 첫 API에서 정지 안내
- 이사한 블로그에 남은 글은 옛 주소에서 그대로 보임(블로그 301을 먼저 적용하면 무한 리다이렉트)
- 연타 방지에서 첫 요청이 3초 넘게 처리 중이면 429 `TOO_MANY_REQUESTS`
- 스텝 범위 밖 엔티티: `ModerationLog`(정지 사유), `Subscription`(구독자 공개 판단)
