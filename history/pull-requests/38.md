## 스텝 23: 스키마·코드·테스트
- **T123** PostgreSQL용 Flyway V1(옛 V1·V3 + post_embedding)
  - citext + 길이 CHECK, IDENTITY, BOOLEAN, `COMMENT ON`
  - `post_embedding`은 post 외래 키
  - V3·V4와 `db/recommend` 삭제
- **T124** MySQL 전용 SQL 바꾸기
  - `INSERT IGNORE` 8곳 → `ON CONFLICT DO NOTHING`
  - `UPDATE`·`DELETE … JOIN` 7곳 → `FROM`·`USING`
  - `updated_at = updated_at` 15곳 삭제
- **T125** 대소문자 무시: citext, 검색은 ILIKE, 접속 설정 `stringtype=unspecified`
  - 이 설정이 없으면 JDBC가 값을 `varchar`로 보내서 citext 비교가 대소문자를 가린다
- **T126** DB 하나로
  - 두 번째 DataSource 삭제
  - 의미 검색·비슷한 글을 Criteria 한 쿼리로(hibernate-vector, 가시성 조건을 같은 쿼리에서)
- **T127** 잠금·격리 주석을 READ COMMITTED 기준으로
- **T128** pom, Testcontainers(pgvector 하나), docker compose(MySQL 삭제, DB `blog`), 테스트 SQL
