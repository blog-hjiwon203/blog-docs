## T088 비밀번호 재설정과 메일로 잠금 풀기 (OWN-02, R-17)
- `POST /api/auth/password-reset {email}` → 202 (가입 안 된 이메일도 같은 응답, 같은 이메일 1분에 한 번 → 429)
- `PUT /api/auth/password-reset {token, newPassword}` → 204 (30분, 한 번만, 바꾸면 다른 링크도 못 씀, 그 이메일의 로그인 잠금 풀림) / 400 `RESET_TOKEN_INVALID`
- 링크 토큰은 256비트 임의 값, DB(`password_reset_token`)에는 SHA-256만
- 로그인이 이메일별 횟수 제한에 걸리면 가입한 이메일이면 "본인이면 이 링크로" 메일(15분에 한 번)
- 메일은 `app.mail.sender`로 log·smtp 선택(`spring-boot-starter-mail`). 커밋 뒤 다른 스레드에서 보내 응답 시간으로 가입 여부가 드러나지 않게 함
- 화면: `/password-reset`(메일 받기, 링크로 새 비밀번호), 로그인 화면 "비밀번호를 잊었어요", 잠금 시 메일함 안내

## T099 카카오 로그인·가입·재인증 / T100 연동·해제 (AUTH-01, OWN-03, AUTH-06, R-07)
- **구글 로그인은 뺌**(2026-10-12 지원 결정): 구글은 리다이렉트 URI가 https여야 하는데 운영 주소가 http라 쓸 수 없음. `/api/auth/oauth/google/...`은 404
- `GET /api/auth/oauth/kakao/authorize?mode=login|link|reauth&redirect=` → state를 Redis(10분)와 `oauth_state` 쿠키에 두고 제공사로 302
- `GET /api/auth/oauth/{provider}/callback` → state 한 번 쓰고, code → 제공사 회원 번호, 2분짜리 표로 시작한 플랫폼 주소의 `complete`로 302
- `GET /api/auth/oauth/complete?ticket=` → 쿠키 state 확인(로그인 CSRF 방지) 후 로그인 / `/signup/social` / 연동 / 재인증
- `POST /api/auth/oauth/signup {signupToken, nickname}` → 201 Me + 쿠키 (회원과 `social_account`를 한 트랜잭션)
- `DELETE /api/me/social/{provider}` → 204 / 409 `LAST_LOGIN_METHOD`
- 탈퇴: 소셜 재인증 10분 안에 `DELETE /api/me {}`
- `Me.socialAccounts` 채움. 제공사 이메일은 받지도 저장하지도 않음
- 화면: 로그인 화면 카카오 버튼, `/signup/social` 닉네임 확인, 마이페이지 소셜 연동·해제, 탈퇴 화면 소셜 본인 확인
- 테스트는 가짜 제공사(`FakeOAuthClients`)로 흐름 전체를 돈다
